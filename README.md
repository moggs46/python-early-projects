# Early Python Projects

Some of the first programs I wrote in Python.

| Program | Description |
|---|---|
| `shark_interest_calculator.py` | Compound interest loan calculator. Tracks interest, principal and payments in 5-week periods, then draws a principal-vs-interest bar chart with Tkinter. |
| `super_alto_travel.py` | Calculates how many train cars are needed for a trip and the travel time for each leg based on wind conditions. |
| `country_guesser.py` | A country guessing game with hints and a configurable number of guesses. |

## How to run
```bash
python <file_name>.py
```
